# Portfolio Website Template

A sleek, modern portfolio website built with Next.js 14 and Tailwind CSS.

## Features
- ✅ Fully responsive design
- ✅ Purple/pink gradient theme
- ✅ Hero section
- ✅ About section with stats
- ✅ Projects showcase
- ✅ Contact section
- ✅ Smooth animations
- ✅ SEO optimized

## Getting Started
```bash
npm install
npm run dev
