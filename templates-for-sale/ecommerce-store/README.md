# E-commerce Store Template

A modern, responsive e-commerce store built with Next.js 14 and Tailwind CSS.

## Features
- ✅ Fully responsive design
- ✅ Product catalog
- ✅ Shopping cart
- ✅ Category filters
- ✅ Newsletter signup
- ✅ Modern clean UI
- ✅ SEO optimized
- ✅ Fast loading

## Getting Started

Install dependencies:
npm install

Run development server:
npm run dev

Open http://localhost:3000

## Build for Production

npm run build
npm start

## Customization

- Colors: Edit tailwind.config.js
- Content: Edit files in src/app/
- Components: Edit files in src/components/
