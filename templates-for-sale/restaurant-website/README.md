# Restaurant Website Template

An elegant restaurant website built with Next.js 14 and Tailwind CSS.

## Features
- ✅ Fully responsive design
- ✅ Warm amber/red theme
- ✅ Hero section
- ✅ About section
- ✅ Menu showcase
- ✅ Reservation form
- ✅ Contact section
- ✅ SEO optimized

## Getting Started

Install dependencies:
npm install

Run development server:
npm run dev

Open http://localhost:3000
