# Blog Platform Template

A clean, modern blog platform built with Next.js 14 and Tailwind CSS.

## Features
- ✅ Fully responsive design
- ✅ Featured post section
- ✅ Recent posts grid
- ✅ Newsletter signup
- ✅ Clean light theme
- ✅ SEO optimized
- ✅ Fast loading

## Getting Started

Install dependencies:
npm install

Run development server:
npm run dev

Open http://localhost:3000

## Build for Production

npm run build
npm start

## Customization

- Colors: Edit tailwind.config.js
- Content: Edit files in src/app/
- Components: Edit files in src/components/
